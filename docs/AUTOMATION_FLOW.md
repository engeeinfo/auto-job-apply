# Automation flow

1. Log in and open recommended jobs.
2. Extract each job's title, experience, and company.
3. Skip jobs requiring more than four years' experience.
4. Ask the configured AI provider to score eligible jobs.
5. Select approved jobs in batches of five.
6. Answer application questions using resume data.
7. Submit, log the result, and stop at the daily application limit.

The browser automation must respect the site's terms, configured rate limits,
and user review requirements.
